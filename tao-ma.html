Mã dán vào thẻ HTML tùy chỉnh

    

    
    
      
  1. Mở Google Tag Manager của web, chọn Thẻ → Mới → HTML tùy chỉnh.
    2. 
      
  2. Dán mã vừa sao chép, chọn trình kích hoạt All Pages, lưu lại.
    3. 
      
  3. Bấm Gửi → Xuất bản. Gửi tên miền web cho bên cài đặt để kích hoạt gói.
    4. 
      
  4. Nếu web đang có thẻ nút Zalo/Facebook cũ, tạm dừng thẻ đó để không bị trùng nút.
    5.
